# Ares Inter GmbH — Landing Page (v2)

Modern landing page with mobile nav, images, Formspree-ready contact form, and legal sections.

## Quickstart
npm install
npm run dev

## Contact Form
Replace `YOUR_FORM_ID` in `src/components/AresInterLanding_v2.tsx` with your Formspree ID (create at formspree.io).

## Deploy
npm i -g vercel
vercel && vercel --prod
